# Requirements

## Hardware Requirements

- Any modern computer.

## Software Requirements

- **To run the code generator:** Rust programming language (latest version). You can install Rust by following the instructions at <https://rust-lang.org/tools/install>.
- **To run the Python scripts:** Python 3.8 or higher. You can install Python by following the instructions at <https://www.python.org/downloads/>.
- **To run the tests on ModelSet:** The `modelset_coverage.py` script the ModelSet dataset to be downloaded and available on your local machine. You can download the ModelSet dataset from <https://github.com/modelset/modelset-dataset>.
