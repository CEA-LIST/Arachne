# Artifact Status

We apply for the **Available** and **Reusable** badges.

## Available

The artifact is publicly available in the accompanying repository. It contains the source code, benchmark inputs, scripts, and documentation required to inspect and run the implementation described in the paper.

## Reusable

We believe the artifact deserves the Reusable badge because it is documented, self-contained, and includes step-by-step instructions for installation, execution, and reproduction of the main experiments. The repository also provides example metamodels and expected outputs, making it possible for other researchers to reuse and extend the artifact.
